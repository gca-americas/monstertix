# Module 1 — You cannot prompt your way to autonomy

A good agent that is also useless at the only moment that matters.

**New here:** `Agent`, plain function tools, `adk web`.

**Try it**
> "I want to see The Midnight Signal. Amsterdam, going with Sam, ~$200 each."

It searches, reads seat maps, reasons well. Then 10:00 Tuesday arrives and it
does nothing, because nothing called it.

**The line that matters:** none. That's the point — no prompt fixes absence.
